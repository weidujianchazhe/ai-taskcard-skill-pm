# 技能复盘记录（元管理回路）

> **服务对象**：项目管理技能本身（不是项目工作复盘——项目总结归 reports\）。
> **触发**：① 事件自动采集——任务卡重建 / STATE 恢复 / 锚点断链 / 越界改文件等任何「恢复动作」发生时，顺手记一行阻碍点（无需等人发起）；② 人工复盘——项目收尾 / 定期复盘 / 使用中遇阻。
> **记录方式**：追加式，每轮四段、每段一句话（防膨胀）。
> **存储位置（元管理分流）**：全部复盘事件追加写**项目工作区根 `REVIEWS.md`**（初始化时由本模板实例化）——**不写 reports\、不登 INDEX**。工作区 REVIEWS.md 中标「建议提级」的条目，由管理者人工摘录回**技能源包**统一处置；源包只收提纯后的通用改进（保持干净可分享）；改进落地时同步源包模板并递增版本。
> **裁决者**：管理者（项目或技能的实际负责人，初始化时在 MAP 环境段登记）；暂缓项在「第 3 次复发」时自动翻案复审。
> **闭环**：阻碍 → 根因 → 建议 → 处置 → 落地（按 SKILL 维护规范：先改权威源 SKILL.md → 同步 README/MAP 派生快照 → 三处版本一致）→ 再使用。
