# 定时任务规范（schedule\）

> 提醒 / 周期检查 / 定期汇报。**实现靠各平台定时能力**（本技能只放规范，不打包实现）。

## 用途

| 类型 | 例子 | 关联 |
|---|---|---|
| 定时提醒 | 会议提醒、截止提醒 | — |
| 周期检查 | 每日/每周项目状态检查 | 与 `checks\` 开关联动（默认关闭，开启才执行） |
| 定期汇报 | 日报/周报生成 | 见 `report\` |

## 约定

1. 定时任务触发时，在执行指令中明确声明「本次请求由定时任务 [任务名] 触发」
2. 周期检查遵守 `checks\` 开关：默认关闭，管理者开启后才由 AI 定期执行
3. 定时产出的记录按现有协议沉淀（reports\ + INDEX + STATE），不另建体系
4. 不把定时实现写进技能——各平台用自身定时能力，产出对齐本协议即可
5. **平台没有定时能力** → 读 `custom\` 指南生成本地脚本（Windows 计划任务 / Linux cron）
